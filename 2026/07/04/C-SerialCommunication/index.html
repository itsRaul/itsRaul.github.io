串口通信详解：从基本原理到 C# 上位机工业现场应用

在 C# 上位机、SCADA、MES、工业自动化、设备监控等项目中，串口通信是非常基础也非常重要的一项技术。

例如：

  • 上位机读取空压机运行数据
  • 上位机读取电表、电流表、电压表
  • 上位机控制水泵、风机
  • PLC 与电脑之间交换数据
  • 温度、压力、流量传感器向上位机发送数据
  • 变频器接收启动、停止、频率设置命令
  • 工业仪表通过 RS485 接入监控系统
  • 多台设备通过 Modbus RTU 接入 SCADA 系统

这些场景背后，经常都能看到：

四十五、“什么是串口通信？”

串口通信是一种按照顺序逐 bit 传输数据的通信方式，在工业自动化和上位机开发中应用非常广泛。常见的接口有 RS232、RS485，其中 RS232 更适合点对点通信，RS485 更适合工业现场的多设备总线通信。

在实际项目中，我接触比较多的是 RS485 + Modbus RTU。上位机通过 USB 转 RS485 接口形成 COM 口，配置波特率、数据位、校验位和停止位，然后按照设备通信协议组装请求帧，通过串口发送给 PLC、变频器、电表、传感器等设备，接收到数据后进行帧解析、CRC 校验和数据转换，最后把结果展示在 WPF 上位机界面。

实际开发中还需要处理通信超时、重试、设备离线、数据缓存、CRC 校验以及多设备轮询等问题。

这个回答已经比较接近实际上位机开发工程师的面试表达。
